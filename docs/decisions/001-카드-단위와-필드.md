# 001. 결정 카드의 단위와 필드

- **결정**: 결정 1개 = 카드 1장. 버린 대안은 `{option, reason_rejected}` 배열, 근거는 로그 메시지 인용(`log_id`, `message_index`, `quote`)으로 둔다. 카드에는 근거가 반드시 있어야 하고, `status`는 LLM이 확정하지 않는다.
- **이유**: 한 카드에 결정이 섞이면 판정과 평가가 흐려지고, 대안마다 이유를 따로 둬야 장면 ①의 "기각 이유"를 보여줄 수 있다. 인용문을 원문과 대조할 수 있어야 환각을 검사할 수 있다.
- **대안**: 카드 1장에 여러 결정을 묶기(평가·판정이 모호해져 기각), 근거를 자유 문장으로 두기(인용 검증 불가로 기각).
