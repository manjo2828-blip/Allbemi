# 003. 예시 데이터는 마케팅팀 시나리오를 우선으로

- **결정**: 예시 데이터는 합성 프로젝트 2개로 한다. 마케팅팀(여름 신제품 런칭 캠페인)을 기본(우선) 시나리오로, 개발팀(로그 시스템 개편, MongoDB 시나리오)을 두 번째로 둔다.
- **이유**: 마케팅팀에서도 이 서비스를 유용하게 쓸 수 있다는 점을 보여주고, 개발 전용 서비스로 보이지 않게 한다. 4종 판정·3종 상태·확인 필요·파일 첨부를 모두 한 시나리오 안에서 시연할 수 있다.
- **대안**: 학원 시나리오(수업 자료 첨부 예시와 잘 맞지만 도메인이 좁아 보임), 개발팀 단일 시나리오(사용 범위가 좁아 보임).
