# 004. 예시 데이터는 contracts/examples/ 한 곳에만 둔다

- **결정**: 프론트(가짜 API), 백엔드(시드), 평가(정답 데이터의 씨앗)가 `contracts/examples/`의 같은 JSON을 쓰고, `scripts/validate_examples.py`로 스키마와 무결성을 검사한다. 합성 데이터만 쓴다.
- **이유**: 같은 데이터를 세 곳에 따로 만들면 반드시 어긋난다. 검증 스크립트가 있으면 계약이 바뀔 때 예시도 함께 갱신해야 한다는 것을 강제할 수 있다. 공개 저장소이므로 실제 자료를 쓰지 않는다.
- **대안**: 분야별로 각자 mock 데이터를 만들기(불일치 발생), 검증 없이 수동 관리(오류가 늦게 발견됨).
