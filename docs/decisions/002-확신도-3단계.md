# 002. 확신도는 high / medium / low 3단계

- **결정**: 확신도는 `high` / `medium` / `low` 3단계만 쓰고, `low`이면 `needs_review`를 반드시 `true`로 한다. 퍼센트·점수는 쓰지 않는다.
- **이유**: LLM이 말하는 숫자는 보정되어 있지 않아 화면에서 정확해 보이는 착각을 만든다. 3단계는 "확인 필요" 표시와 바로 연결된다. (확신도 보정 평가는 별도로 측정한다.)
- **대안**: 0~1 숫자 확신도(보정되지 않아 오해 유발), 확신도 없이 항상 확정 표시(자동 생성의 신뢰 문제 해결 불가).
